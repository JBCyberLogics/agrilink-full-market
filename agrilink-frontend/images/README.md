# Hero image credits

These locally stored WebP images are used by the AgriLink marketplace hero.
They were downloaded from Unsplash for build-time delivery and are available
under the Unsplash License.

- `agriculture-field.webp` — Arnold Krausz, “Green wheat field under low sun”
  — https://unsplash.com/photos/green-wheat-field-under-low-sun-yjo6PtUs7Ko
- `harvest-aerial.webp` — Urs Lendermann, “A green and white truck driving across a field”
  — https://unsplash.com/photos/a-green-and-white-truck-driving-across-a-field-Uoc2JtX7o6k
- `farmland-sunrise.webp` — Bernd Dittrich, “Aerial view of green and brown agricultural fields”
  — https://unsplash.com/photos/aerial-view-of-green-and-brown-agricultural-fields-3vgvdshL0_0

Vite discovers supported image files directly in this folder at development
or production build time. Adding a file affects the next build; deployed builds
do not detect runtime uploads without an image manifest or storage service.
